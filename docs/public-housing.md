# 公的住宅・自治体空き家データ

## 参考資料と募集を混ぜない

団地の存在、空き住戸数、申込受付中は別の事実です。台帳には家賃や現在の空室がないため補完しません。空き住戸数には補修中・入居手続中・事業用確保分が含まれることがあり、数があっても募集中とは限りません。

画面は参考レイヤーとして表示し、共通条件での絞り込みは利用者が有効にします。厳密な判定では、概略座標・不明費用・不明間取り・現在の募集未確認は一致にしません。未確認を含める場合も、判明している価格超過や概略位置での半径外は除外します。台帳の間取り・面積の範囲は特定住戸の値ではないため、単一値の条件には未確認です。公開資料には建設年度を竣工日と見なした築年数や、直線距離からの通勤時間を付けません。

## 取得する公式データ

### 東京都 都営住宅団地一覧

- [公式配布ページ](https://www.juutakuseisaku.metro.tokyo.lg.jp/toei_jutaku/kanri/toeidanchi) の「全区市町 オープンデータCSV」を使用。
- [東京都カタログ](https://catalog.data.metro.tokyo.lg.jp/dataset/t000030d0000000009) は **CC BY 4.0**。出典は東京都住宅政策本部。加工した住所・数値と原文の範囲を区別して表示します。
- カタログAPIでライセンスを確認し、現在の配布ページからCSVリンクと「○年○月○日現在」を読み取ります。カタログの古いダウンロードURL・最終更新日を資料基準日としません。
- 住所・団地名・管理戸数等の台帳です。2026-10-18の実取得時、基準日は2025-03-31でした。募集状態・家賃・空き住戸数はこのCSVにありません。現在の募集には使用しません。

### 津幡町 空き家バンク（全国対応の自治体接続例）

- [公式オープンデータ](https://catalog-data.city.kanazawa.ishikawa.jp/dataset/173614_empty_bank) の公開CSV/CKAN API。出典：津幡町（金沢市オープンデータポータル）、**CC BY**。
- APIでライセンス・リソースID・配布URLを確認してからCSVを取得します。条件が変われば停止し、許諾未確認のURLへ自動追従しません。
- 成約済み・募集終了・受付終了は除外。「受付中」は**公開時点の申告**であり現在募集中とはしません。CSVに物件ごとの確認日時や基準日がないため、`data_as_of` は不明、`source_updated_at` は公開ファイルの更新日です。
- 売買価格は円、賃貸は備考に月額の明記がある場合のみ月額家賃として採用。管理費などは不明のままです。個別掲載URLが空欄なら公式データセットへ案内します。町字までの住所は住戸の正確な所在地ではありません。
- 2026-10-18の実取得時はファイル更新日2026-09-14、成約済み23件を除外し、公開時点受付中3件でした。これは動作検証時点のスナップショットで、現在の空室数の保証ではありません。

### 取得しないサイト

- [都営空き住戸数](https://www.juutakuseisaku.metro.tokyo.lg.jp/toei_jutaku/kanri/264-01toeidanchi) は公式PDFへのリンクのみ。[サイトポリシー](https://www.juutakuseisaku.metro.tokyo.lg.jp/policy) は無断転載を包括的には認めておらず、空き住戸PDFについてCC BY等の許諾を確認できないため自動取得・転載しません。
- [都営募集](https://www.to-kousya.or.jp/kouei/toeibosyu/toeitop_gdn.html)、[UR](https://www.ur-net.go.jp/chintai/)、[JKK東京](https://www.to-kousya.or.jp/chintai/) は公式検索・申込導線。許諾済みAPIは未接続です。
- [国交省の全国版空き家バンク案内](https://www.mlit.go.jp/totikensangyo/const/sosei_const_tk3_000131.html) と [LIFULL](https://www.homes.co.jp/akiyabank/) は外部リンクです。全国版ポータルや自治体の通常HTMLを巡回・スクレイピングしません。**全国網羅ではなく、現状の自治体自動接続は津幡町のみ**です。

## 取得・位置検索の境界

ネットワーク先はアダプター内の公式許可リストに限定します。任意URLをAPIパラメーターで渡せません。タイムアウト・サイズ上限を設け、エラー時に過去の成功データを新規取得として返しません。画面では同じソースの再取得開始時に既存結果を消去します。データ取得は利用者の操作時のみで、プロセス内キャッシュの取得日時は再利用時も書き換えません。

住所は [国土地理院 住所検索（協力：東大CSIS）](https://maps.gsi.go.jp/) へ送信します。連続照会はプロセス全体で1.1秒以上の間隔、1操作につき最大5件です。位置結果を1時間キャッシュし、住所の郡・字・丁目表記を照合します。住所の一致が確認できない結果は未確認のままです。結果は常に概略座標で、実住戸の位置や距離を保証しません。大量照会用サービスではありません。

一覧は地域名・団地名で検索した20件単位のページです。読み込んだページだけを地図・共通条件で判定します。全件の位置を一括取得しないので、**半径内の全物件を網羅した検索ではありません**。初期地域は千代田区。会社・駅・住所検索で地点A/Bを変えると取得済みレコードの距離判定も更新されます。地域・ソースを変えた場合は再取得してください。

重複排除はソースと提供元IDが基本です。東京都は団地名・住所・面積・間取り・建設年度の組を使い、同じ団地でも異なる住棟・住戸タイプを誤って統合しません。別ソースの住所が一致するだけでは同一住戸と判定しません。クロスソースの同一住戸照合は未対応です。

同じ座標の資料は件数ピンにまとめ、クリックするたびに該当資料を順に選択します。地図上の位置をずらして正確に見せることはしません。通常のピンは価格付き、価格不明なら未確認表示です。

## 許諾済み空き住戸数・募集フィード

自動接続できない情報は、提供元から利用許諾を得たJSONを管理者が用意します。`PUBLIC_HOUSING_FEED_PATH=/absolute/path/public.json python3 server.py` で接続し、画面の「許諾済み公的住宅フィード」を取得します。ファイルは静的配信されません。フラグは許諾そのものを取得する機能ではなく、契約・更新管理は運用者の責任です。未設定時はレコードを創作しません。

以下は形式確認専用の架空例です。実在募集として使わないでください。

```json
{
  "permitted": true,
  "license": "TEST ONLY / 提供元の利用許諾に置換",
  "license_url": "https://example.com/permission",
  "records": [{
    "id": "TEST-ONLY",
    "name": "形式確認専用・実在物件ではありません",
    "address": "形式確認専用",
    "layer": "vacancy",
    "kind": "rent",
    "source_url": "https://example.com/source",
    "data_as_of": "2026-03-31",
    "vacancy_public": 7,
    "vacancy_reserved": 1
  }]
}
```

`layer` は `inventory` / `vacancy` / `recruitment` / `municipal`。同じ提供元IDでもレイヤーが違えば別レコードです。出典HTTPS URL・基準日・利用条件を必須とします。任意の `official_url` がなければ `source_url` を掲載リンクに使います。価格は `price_yen`、間取りは `layout`、面積は `area`、築年は `age`、月額費用は `management_fee_yen` / `mandatory_fee_yen`。不明値は省略またはnullで、0に置換しません。座標 `lat` / `lon` と `geo_precision`（`exact` または `approximate`）は提供元に基づく場合のみ指定します。

`recruitment` には `availability_status: "confirmed"` と、タイムゾーン付き `last_verified_at` が必要です。提供元が確認した日時から1時間以内だけ表示し、将来・未確認・期限切れ・終了は除外します。`vacancy` の数字があっても募集状態をconfirmedに変換しません。`ended` はすべてのレイヤーで除外します。

## 検証の区別

CIは固定フィクスチャによるCSV正規化、鮮度・不明値・許諾・URL制約、共通条件、実UIハンドラー経由の読み込み/ジオコーディング/ピン切替を検証します。公開サービスへの通信はCIの成否に依存させません。実際の公式CSV取得とブラウザー地図表示は別途手動で確認しています。許諾済みフィードのテスト例は実際の募集との接続実証ではありません。
